🚀 1단계: 아래 버튼으로 완성된 파일 저장 또는 코드 복사

이전에 휴대폰에서 0 kcal로 멈췄던 이유는 카카오톡/내파일의 '임시 뷰어(content://)'로 열렸기 때문입니다. 정식 웹페이지로 올리면 삼성 브라우저에서 카메라 촬영과 계산이 100% 작동합니다!

💻 방법 A. 깃허브(GitHub Pages) - 개발자 사이트 무료 평생 호스팅
  1. github.com 로그인 후 우측 상단 [+] → [New repository] 클릭
  2. Repository name에 diet 입력 후 Public 체크 → [Create repository]
  3. [creating a new file] 클릭 → 파일 이름에 index.html 입력
  4. 위에서 복사한 전체 코드를 붙여넣고 우측 상단 초록색 [Commit changes] 클릭
  5. 상단 [Settings] → [Pages] 메뉴에서 Branch를 main으로 선택 후 [Save]하면 1분 뒤 평생 무료 주소(아이디.github.io/diet)가 생성됩니다!
⚡ 방법 B. 10초 컷 무료 호스팅 (Tiiny.host 또는 Netlify Drop)

가입이나 복잡한 설정이 귀찮다면 tiiny.host 또는 app.netlify.com/drop 사이트에 접속해서 위에서 받은 index.html 파일만 올리면 즉시 전용 웹페이지 주소(URL)가 만들어집니다.

💡 꿀팁: 만들어진 주소를 삼성 인터넷 브라우저에서 연 뒤, 우측 하단 메뉴(≡) → [현재 페이지 추가] → [홈 화면]을 누르시면 바탕화면에 실제 앱 아이콘처럼 생겨서 터치 한 번으로 바로 켜집니다!
